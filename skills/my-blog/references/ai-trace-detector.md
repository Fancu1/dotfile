## 句式黑名单（优先级 P2）

- "**首先...其次...最后...**" 完整三段式（"其次" 出现 >1 次/篇视为命中）
- **连续 3 段以上长度均匀**（每段 4-6 句、80-150 字之间，没有节奏变化）
- **正文 emoji**（文末固定卡片除外）
- **"X 是 Y" 判断句堆叠**（≥3 次出现在同一段落）

## 主题套话开头（优先级 P1）

绝不允许出现在文章前 2 句：
- "在这个 XX 的时代"
- "随着 XX 的不断发展"
- "在当今 XX 的背景下"
- "众所周知，..."

## 翻译腔（优先级 P2）

| 翻译腔 | 改成 |
|---|---|
| "做了什么 + 的事情" | 直接"做了什么" |
| "进行 X 化处理" | "处理 X" / "X 化" |
| "通过 X 的方式" | "用 X" |
| "在 X 方面" | "X 上" / "X 这块" |
| "对于 X 而言" | "X 来说" / 直接省略 |
| "作为 X 的一种" | "一种 X" |

## 互联网黑话（优先级 P1）

绝不在正文出现（自嘲调侃语境例外）：

```
赋能
抓手
闭环
心智
颗粒度
对齐
拉齐
拉通
打通
沉淀
壁垒
护城河
心智模型（除非真在讲 Mental Model 概念）
```

## 营销 / 公众号体（优先级 P1）

- "你不知道的 5 个 X"
- "震惊！X 竟然 Y"
- "看完这篇你就懂了"
- "干货满满"
- "保姆级"

## 收尾套话（优先级 P1）

绝不允许出现在文章最后 3 段：
- "通过本文，我们可以看到..."
- "总而言之，本文介绍了..."
- "希望本文对您有所启发"
- "如果你觉得本文有帮助，请点赞..."

## 使用方式

| 阶段 | 加载方式 |
|---|---|
| Stage 1.b 写草稿 | LLM 写每段后对照禁用词清单 + 句式黑名单 grep 自检 |
| Stage 2.a 终稿补丁 | 调 deai skill 后，从 diff 反推 patch 候选，按 P1/P2 排序应用 Top 5-10 |
