# Python 语言补充

版本：`python-1`。仅启用 Python 时处理。以下补充公共项，不是所有语言的要求或已批准的规范。

| 编号 | 确认问题 | 推荐起点 |
|---|---|---|
| PY-01 | 格式、命名、类型标注和公开说明采用什么惯例？ | 沿用项目实践，标注帮助理解契约，不默认全量标注或固定工具链。 |
| PY-02 | 异常捕获、转换、链式原因和传播边界是什么？ | 捕获能处理的异常，保留原因；不无理由吞异常或统一框架。 |
| PY-03 | 文件、连接等资源如何在异常路径释放？ | 按资源协议使用上下文管理或清理，不强制所有资源同一写法。 |
| PY-04 | 异步任务、线程工作的取消、等待和失败观察由谁负责？ | 考虑阻塞调用和任务生命周期，不把运行时特性当成共享状态天然安全的保证。 |
| PY-05 | 可变默认参数、共享对象和导入副作用如何避免意外状态？ | 明确有意共享和生命周期，避免调用者不可见的状态污染，不规定应用架构。 |

重合部分引用公共规则，只写语言特有补充。不要把 Go 错误返回和并发写法推广到 Python。精确版本行为或工具选择依据当前项目或官方资料。
