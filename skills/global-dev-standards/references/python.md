# Python 语言补充

仅涉及 Python 时读取。产出为 `languages/python.md`，与公共正文互补；具体程度应与 Go 成品相当，但无需读取或生成 Go 文件。以下为推荐起点，结合明确偏好和已有规则选择，不变成问卷。

| 编号 | 内部检查内容与推荐写法 |
|---|---|
| PY-01 | 变量、函数、方法用 snake_case，类型用 PascalCase，常量用 UPPER_SNAKE_CASE；缩写保持可读，布尔名称表达状态，集合名称表达业务内容。格式工具沿用项目配置，不全局锁定工具链。 |
| PY-02 | 捕获能够处理的具体异常，不用宽泛捕获加空结果掩盖失败；确需在任务边界兜底时保留失败信息。转换异常时按需要用 `raise ... from exc` 保留原因。 |
| PY-03 | 资源支持上下文管理时优先用 with/async with；其他资源安排可靠清理，考虑异常路径。 |
| PY-04 | 异步任务有管理者、等待或取消路径和失败观察；避免在事件循环中直接运行阻塞工作。线程共享状态仍需明确访问责任，不依赖运行时实现细节假定安全。 |
| PY-05 | 不使用列表/字典等可变对象作普通默认参数；需要新对象时使用 None 哨兵并在调用内创建。避免导入时启动服务、网络操作或后台工作，有意共享的状态明确生命周期。 |
| PY-06 | 实例方法用 self，类方法用 cls；不使用实例或类职责的独立逻辑不机械挂到类上。属性读取不隐藏高成本 I/O 或重要状态变化。 |
| PY-07 | 多个容易混淆的布尔或同类型参数优先采用有意义的关键字调用，必要时设计仅限关键字参数；不为每个小函数增加配置对象。 |
| PY-08 | 对公开接口及类型不易推断的边界优先添加准确类型标注，局部显然变量无需重复。不要用 Any 掩盖已知契约，也不为标注引入不必要的循环依赖。 |
| PY-09 | 公开 API 用 docstring 描述用途和必要的参数、返回、异常及副作用；内部代码注释解释原因。沿用项目已有 docstring 风格；无既定格式时使用简洁摘要和必要分段，不堆空栏目。 |

输出自然的命名、函数与类型、异常、资源与并发、注释章节，不输出此表。公共注释语言不重复规定一遍。具体运行时版本行为、工具选择有疑问时核实官方资料，不把 Go 的错误返回或接口写法套到 Python。
