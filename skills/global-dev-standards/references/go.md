# Go 语言补充

版本：`go-1`。仅启用 Go 时处理；公共项仍适用。以下是确认提示，不是自动生效的规则。

| 编号 | 确认问题 | 推荐起点 |
|---|---|---|
| GO-01 | 格式、命名及公开说明遵循什么 Go 惯例？ | 采用常见语言表达，工具配置和版本归项目。注释语言不由格式化惯例决定。 |
| GO-02 | 错误返回、包装、判断与 panic 的边界是什么？ | 预期失败通过错误语义表达，保留可判断原因；不一概禁止 panic 或重复打日志。 |
| GO-03 | goroutine 的退出、取消和失败观察由谁负责？ | 考虑请求结束、后台生命周期和 context 传播；不固定协程池或所有函数必须带 context。 |
| GO-04 | 共享内存、channel 关闭和等待由谁负责？ | 明确所有权和同步责任，不要求凡并发必加锁。 |
| GO-05 | defer 与资源获取/释放的作用域如何匹配？ | 考虑循环、错误路径和延迟释放成本，不把语法等同无泄露证明。 |

重合部分引用公共规则，只写 Go 特有解释。不默认框架、ORM、目录分层、微服务或测试工具。精确工具行为依据当前项目或官方资料。
