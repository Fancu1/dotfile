# Go 语言补充

生成 Go 时同时读取 [Go 成品样例](../assets/go.md)。样例是输出具体程度的基准，不能把下表当成正文，用“遵循 Go 惯例”代替实际约定。只在偏好、项目兼容或实际适用性需要时调整默认，不凭空增加框架与架构约束。

| 编号 | 内部检查内容 |
|---|---|
| GO-01 | 格式化，导出与非导出命名，缩写，包名，布尔/集合/映射名称，以及短变量的适用范围。 |
| GO-02 | 错误返回与 panic，错误上下文、错误链和判断，有意忽略，以及避免逐层重复日志。 |
| GO-03 | goroutine 的管理、退出、取消和失败观察；请求生命周期与独立后台生命周期；context 传递。 |
| GO-04 | 共享状态的同步，channel 关闭责任，不强制统一锁或 channel 机制。 |
| GO-05 | 资源获取、defer 释放范围，以及循环中及时清理。 |
| GO-06 | 动作函数命名、避免重复类型名；方法与独立函数的选择；接收者名称和指针语义。 |
| GO-07 | 参数可读性、context 参数位置、显式初始化和可理解的调用契约，不隐蔽依赖调用顺序。 |
| GO-08 | 具体类型、any 使用边界、按使用方需要建立接口，避免机械生成接口和构造选项。 |
| GO-09 | 导出 API 注释形式与内容，内部注释适用情况及例外；注释语言由公共/项目约定决定。 |

原有 GO-01 中的公开说明在 GO-09 具体化；补充 GO-06 至 GO-08 防止遗漏方法与调用风格。此关联只帮助 Skill 维护，不输出清单演进记录。新建议应可执行且有边界，不固定行数、ORM、微服务、目录分层或测试框架。
