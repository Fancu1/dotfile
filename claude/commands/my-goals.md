维护 `~/.claude/goals.md`。**接受自然语言输入，不用子命令**。

## 输入解析

### 无参数

1. 读 `~/.claude/goals.md`
2. 判断状态：
   - **空模板**（chapter 是"（待填）"且各 KPI 段空）→ 进入**首次引导流程**
   - **部分填** → 展示现状 + 问："还没填的：[列出]。继续填、还是改已有的？"
   - **全填** → 展示现状 + 问："改什么？（chapter / 短期 / 季度 / 年度 / 长期，或某条具体 KPI）"

### 带参数（`/my-goals <自然语言>`）

解析意图：

- **换 chapter**：`chapter 换成 XXX` / `当前阶段改为...` → 定位 chapter → 复述确认 → 替换
- **作废 KPI**：`把 Q2 第 2 条作废` / `删掉年度第 3 条` → 定位并复述 → 确认后删除
- **新增 KPI**：`今年新增一条 YYY` / `季度加一个 ZZZ` → 判断段 → 确认后追加
- **标记完成**：`把 XXX 标记完成` / `ZZZ 做到了` → 模糊匹配 KPI → 改 `[ ]` 为 `[x]`
- **歧义** → 复述理解让用户确认："这条像是 [段] 的 [动作]，对吗？"

## 首次引导流程

按顺序问五层。**一次一个问题**，用户可跳过。

### 1. 当前 chapter
"你当前 1-2 个月的阶段重心是什么？（一句话）"
示例回答："拿下 AI 平台方向岗位"、"把第一个生产服务跑通"

### 2. 短期（本周 / 本月）
"这周或这个月要完成的具体事？（3-5 条）"

### 3. 季度 KPI（当前季度）
"本季度要做到的几件大事？（3-5 条，尽量可测量）"

### 4. 年度目标
"今年底你希望达到什么状态？（3-5 条）"

### 5. 长期方向
"3-5 年的大方向是什么？（不用具体，能表达取向就行）"

## 执行逻辑

### 加 / 改 / 删 KPI

1. 定位目标段（根据输入判断；不确定就问"放短期、季度、还是年度？"）
2. 读当前段内容，列给用户
3. 描述具体改动
4. **预览合并后结果**，让用户确认
5. 用 Edit 更新 goals.md

### 更新日志自动维护

以下情况自动追加一行到底部"更新日志"段：
- chapter 换了
- 季度 KPI 新增 / 删除（不是完成打勾）
- 年度目标大改

格式：`- <今日 YYYY-MM-DD>：<一句话描述改了啥>`

小改动（调整 KPI 措辞、打勾完成）**不**记日志。

### 不支持的操作

- **不支持**无脑清空。重置建议通过 `/my-review` 走季度复盘滚动到下季度，或手动编辑。

## 边界

- chapter 换得太频繁（一周内换两次）→ 问："这么快换 chapter，是方向在漂还是在探索？要不要先 `/my-reflect` 想清楚？"
- KPI 不可测量（"更努力"、"变得更好"）→ 追问："怎么算做到？能列个判断标准吗？"
- 年度 / 长期冲突（比如年度要做 AI 平台，长期却写前端）→ 复述矛盾让用户处理，**不替他决定**
- **每次写入前完整预览全文**让用户过一遍再落盘
