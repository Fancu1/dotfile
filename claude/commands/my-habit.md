---
description: 管理习惯追踪 — 自然语言描述意图（无子命令）
---

维护 `~/wpx/my/my-daily/habits.md`。**接受自然语言输入，不用子命令**。

## 输入解析

### 无参数

1. 读 `habits.md`
2. 空骨架 → 直接问："你想开始追踪什么习惯？（上限 5 条）"
3. 已有条目 → 展示当前列表（描述 + 加入日期 + 上次打卡），问："想加新的、归档已完成的、还是光看？"

### 带参数（`/my-habit <自然语言>`）

判断四种意图之一：

**a. 加 habit**
线索词：开始 / 每天 / 每周 / 想 / 坚持 / 追踪 / 加 / 新
例：`/my-habit 每天 7 点起床`
→ 复述："你想加新 habit：'每天 7 点起床'，对吗？" 确认后执行加入。

**b. 归档 habit**
线索词：养成了 / 完成了 / 做到了 / 放弃 / 停 / 删 / 归档
例：`/my-habit 7 点起床养成了`、`/my-habit 放弃每周读书`
→ 模糊匹配 habits.md → 复述："把 '每天 7 点起床' 归档，原因 '已养成'，对吗？" 确认后执行归档。

**c. 查看列表**
线索词：看 / 列表 / 哪些 / 查 / 现在 / 目前
例：`/my-habit 看看我有哪些`
→ 展示 habits.md + 活跃数 X/5。

**d. 歧义 / 判断不出**
展示当前状态，反问意图。**不要自作主张**。

## 执行逻辑

### 加入

1. 数活跃条目
2. **≥ 5 条 → 拒绝**，列当前 habits，要求先归档一条
3. 追加到 `~/wpx/my/my-daily/habits.md`：
   ```markdown
   ## <描述>
   - 加入：<今日 YYYY-MM-DD>
   - 上次打卡：—
   ```
4. 确认："已加入 '<描述>'，当前 X/5。"

### 归档

1. 模糊匹配 habits.md 条目：
   - 1 个匹配 → 直接用
   - 多个 → 列候选让用户选
   - 0 个 → 告知找不到，让用户用"看看我有哪些"确认
2. 问归档原因（若输入未说清）：已养成 / 放弃 / 其他
3. 从 habits.md 删除该条
4. 追加到 `~/wpx/my/my-daily/habits/archive.md`：
   ```markdown
   ## <描述>
   - 活跃期：<加入日期> ~ <今日>
   - 归档原因：<原因>
   - 打卡率：<若能从 journal 算出>
   ```
5. 确认："已归档 '<描述>'。"

### 查看

输出 habits.md 内容（格式化展示每条的描述 / 加入日期 / 上次打卡），附活跃数 X/5。

## 边界

- 描述含特殊字符（冒号 / 括号 / emoji）→ 原样存，别自作聪明清理
- 用户说"不确定是加还是改" → 先模糊匹配已有条目；有相似的问"是想更新 X 吗？"；没有就当加
- 表达含糊（"每天 7 点" 没说做什么）→ 反问清楚，不要猜
